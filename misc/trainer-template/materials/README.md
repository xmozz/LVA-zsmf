Put the course materials here. The suggested layout is:

    materials/slides/       lecture slides (PDF)
    materials/exercises/    exercise sheets, optionally with your solutions
    materials/exams/        old exams and the sample exam
    materials/notes/        handouts, formula sheets, anything else

Other layouts are fine; the agent will inspect the folder. PDFs are read as
rendered pages, so formulas and figures survive. If you have the exam date or
the exact scope (which units the exam covers), put it in a short note here or
tell the agent — those are the two things it usually cannot infer.
